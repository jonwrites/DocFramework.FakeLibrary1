# Introduction

JLib Tools provides a collection of lightweight utilities intended to be shared across JLib applications and services.

The library currently provides basic mathematical operations through the `Calculator` class and simple text transformations through the `TextTransformer` class.

The library is deliberately small and has no application-specific responsibilities. Its purpose is to provide common functionality that can be reused by other JLib components without duplicating basic implementations.
